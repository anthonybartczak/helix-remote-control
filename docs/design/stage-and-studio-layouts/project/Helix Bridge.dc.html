6 · PHONE, LATER
The layout is built from five stackable parts: preset bar, snapshots, chain, parameters, bank tiles. iPad portrait already stacks them. On a phone (below --bp-tablet):
  1. Preset bar splits into two rows: label + name with ‹ ›, then snapshots 1–4 and tempo.
  2. The chain keeps 9 slots in one row but drops names under the nodes; the selected block's name shows above the parameters. Scrolling sideways is the fallback below ~360 px.
  3. Parameters go to one column and fill the screen between chain and bank row.
  4. Bank tiles become a fixed bottom row of four (like iPad portrait), 64 px tall.
  5. The preset browser becomes a full-screen sheet with the same one-bank-per-row list and jump rail.
